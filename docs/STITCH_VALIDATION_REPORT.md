## 4. 이번 세션에서 발견한 참고 사항

- **`hidden` 필드**: Stitch 프로젝트의 각 화면 인스턴스(`get_project`의 `screenInstances`)에는 `hidden: true/false` 속성이 있다. `true`인 화면은 캔버스에 보이지 않지만 **삭제된 것은 아니며 API로는 계속 조회된다.** 이 세션 초반의 "화면이 사라졌다/다시 생겼다" 혼란은 대부분 이 속성과 `list_screens` 조회 API가 숨김 화면을 제외하고 일부만 보여주는 특성 때문이었다.
- **`hidden` 값은 MCP 도구로 변경 불가**: 조회는 가능하지만 콘솔에서 직접 바꿔야 한다.
- **화면 이동(위치 변경) 기능 없음**: MCP 도구에도, Stitch 자체 AI 채팅에도 기존 화면의 캔버스 좌표를 옮기는 기능은 없다. "옮겨달라"는 요청은 새 화면 생성으로 처리된다.

- 더 이상 기준이 아닌 이전 SCR-005 Canonical `1066c843f553496596b12ea12c13e509`(숨김)
